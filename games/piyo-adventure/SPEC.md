# ぴよ氏の冒険 — ゲーム仕様書

**バージョン:** Ver.1.262
**最終更新:** 2026-03-09
**開発:** NullPo Works

---

## 1. ゲーム概要

| 項目 | 内容 |
|------|------|
| ジャンル | 横スクロールアクション（エンドレスラン系） |
| プラットフォーム | Web（PWA）、iOS/Android予定（Capacitor） |
| 対応言語 | 日本語 / 英語 |
| 画面方向 | 横画面（ランドスケープ）固定 |
| 操作方法 | タッチ操作（モバイル） / キーボード操作（PC） |
| 解像度 | 820 × 450（内部キャンバス） |
| フレームレート | 60 FPS（固定タイムステップ） |
| レンダリング | Canvas 2D（ピクセルアート調） |
| データ保存 | localStorage |

### コンセプト
プレイヤーキャラクター「ぴよ氏」を操作し、自動スクロールするステージを走り抜ける。敵を踏んで倒し、コインを集め、パワーアップアイテムを活用しながら、2400mごとに出現するボスを撃破してラウンドを進める。

## 3. 操作方法

### 3.1 タッチ操作（モバイル）

| エリア | 位置 | 操作 |
|--------|------|------|
| 左移動 | 画面左端 0-18% | タッチ中に左へ移動 |
| 右移動 | 画面左端 18-33% | タッチ中に右へ移動 |
| デッドゾーン | 画面中央 33-70% | 操作なし（誤タップ防止） |
| ジャンプ | 画面右端 70-100% | タッチでジャンプ |

**ジェスチャー:**
| ジェスチャー | 動作 |
|--------------|------|
| 下スワイプ（15px以上 / 500ms以内） | 足場をすり抜ける |
| 上スワイプ（-20px / 500ms以内） | ショップに入る（建物付近） |

### 3.2 キーボード操作（PC）

| キー | 動作 |
|------|------|
| ← / A | 左移動 |
| → / D | 右移動 |
| Space / ↑ / W | ジャンプ |
| ↓ / S | 足場すり抜け |
| Escape / P | ポーズ |

| AIフェーズ | HP残量 | 速度 | 召喚間隔 | 攻撃パターン |

### 6.6 ボスへのダメージ方法

| 方法 | ダメージ | 備考 |
|------|---------|------|

### 6.7 怒りモード
- ストンプ命中後に発動（2.5秒間）
- 移動速度・攻撃速度が2倍に
- 連続ストンプ不可（クールダウン90フレーム）

## 7. ステージ構成

### 7.1 自動スクロール

| パラメータ | 値 |
|-----------|-----|
| 基本スクロール速度 | 1.2 px/frame |
| 速度上昇間隔 | 300mごとに+20% |
| 最大速度 | 基本の5倍（500%） |
| 安全地帯速度制限 | 1.5倍まで |
| ボス戦中 | スクロール停止 |

### 7.2 バイオームシステム

2400mの周期で4つのバイオームが循環（各600m）:

| インデックス | バイオーム | 地形タイプ | 特殊効果 |
|------------|-----------|-----------|---------|
| 0 | 草原 | 通常 | なし（穴あり） |
| 1 | 砂漠 | 流砂 | 移動速度低下、穴なし |
| 2 | 雪山 | 氷 | 慣性増加（滑る） |
| 3 | 夜 | 暗い地形 | 40%暗い夜間オーバーレイ、星空演出 |

- バイオーム間はグラデーションで滑らかに遷移（約2秒間）

### 7.3 地形

| 地形タイプ | 説明 |
|-----------|------|
| ground | 通常の地面 |
| hole | 穴（落下でダメージ） |
| elevated | 高台（60-100px） |
| ice_elevated | 氷の高台 |
| quicksand_elevated | 流砂の高台 |

- 穴出現確率: 15%（砂漠では穴なし）
- 安全地帯（ボス手前250m）: 平坦地形のみ

### 7.4 足場（プラットフォーム）

出現間隔: 120フレームごとに60%の確率

**基本タイプ:**
| タイプ | 出現確率 |
|--------|---------|
| 雲 (cloud) | 50% |
| 浮遊地面 (floating_ground) | 50% |

**特殊足場（20%の確率で付与）:**

| タイプ | 確率 | 効果 |
|--------|------|------|
| 動く足場 (moving) | 8% | 上下に振動（振幅40-70px） |
| 消える足場 (disappearing) | 6% | 乗ると1.5秒後に消滅 |
| バネ足場 (spring) | 6% | 乗ると通常の1.4倍の高さでジャンプ |

- サイズ: 幅120-200px × 高さ30px
- 出現高度: Y 164-286px
